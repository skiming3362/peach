# 任务进度与容器清单

此清单依据用户截图整理，没有可重抓的上游文档 URL，因此不登记到 `docs/reference-sources.json`。

按用户于 2026-09-29 提供的口味、扫描与链接管理截图复核，2026-11-13 按加载态统一方案改写。后台任务有确定总量时显示进度条；未知总量时按做的事显示 loading.dev 语义动画（类别查 `frontend/src/activity-kinds.ts`），同一位置只显示一次状态文字；失败时同一位置换成 `Note`。

独立状态块使用带底色的框；已有任务卡、设置分组或结果面板的状态使用所在容器，不叠加第二层框。两种主题共用语义边框和背景 token。`TaskProgress` 负责这两种容器和「说明 + 横条或动画」的结构，`Progress` 只负责数值图形，`ProgressRing` 只用在图标大小的位置。

| 页面或位置 | 状态与动画 | 容器 |
| --- | --- | --- |
| 口味 | 分析浏览记录 Blocks；导入文件 Gather | 独立底色块，主按钮与下拉半边同步忙态 |
| 数据管理：扫描与采集 | 按阶段：查文件 Radar、抓资料与封面 LinearDots、写候选 Gather、生成预览 Blocks | 扫描任务卡正文，按钮在分隔底栏 |
| 数据管理：媒体修复 | 修复文件，有总量画横条 | 媒体修复任务卡正文 |
| 数据管理：整理 | 检查整理计划 Radar；执行整理 Blocks | 整理任务卡正文，不叠加状态框 |
| 数据管理：链接管理 | 检查链接 Radar；重验并删除 Gather | 站外链接任务卡正文，主按钮在分隔底栏；结果表使用结果面板 |
| 数据管理：资源同步 | 核对文件 Radar；复核与清理 Gather | 文件与记录核对任务卡正文 |
| 关注页 | 检查更新 Radar；往回抓 LinearDots；失败为错误 `Note` | 独立底色块，与其他任务同一套，不再有大圆环和描边盒子 |
| 关注管理：关注列表 | 检查更新 Radar、抓取历史 LinearDots | 关注列表卡正文 |
| 关注管理：添加关注 | 解析链接、按名称查找 Radar | 添加关注卡正文；输入建议的等待点位于建议菜单 |
| 活动 | 每项正在运行的任务按任务类型与阶段；暂停、取消中只写状态 | 活动任务卡正文 |
| 来源和凭证 | 全部检查 Radar（有总量画横条）、抓取封面 LinearDots、重建运行环境 Blocks | 设置分组正文 |
| 配置：更新与维护 | 下载、校验、解压、准备安装；等 Watchtower 重建 Clock | 更新设置分组，保留阶段刻度 |
| 配置：账本备份 | 备份、恢复 Gather；首次读取用骨架 | 设置分组正文 |
| 配置：存储空间 | 统计 Radar；按上次文件数画的横条标明「估算」 | 设置分组正文 |
| 配置：缩略图、关注计划、媒体处理 | 生成缩略图 Blocks、检查关注 Radar、拉取订阅 LinearDots、保存 Gather | 设置分组正文 |
| 页面顶部更新横幅 | 有百分比用小环形；应用迁移 Blocks；连接发布源与下载还没总量 LinearDots；重启与安装 Clock | 横幅图标位 |
| 扫描与采集通知卡 | 图标位：有总量小环形，没有总量按阶段的动画；步骤清单的当前步按步骤的动画 | 紧凑通知栏 |
| 封面网格 | 正在抓的卡片 LinearDots；排队的卡片静止的 Clock | 封面格，尺寸随网格密度 |

统计页的覆盖率、容量、观看比例，口味页的覆盖率，以及媒体卡片的观看进度，表达的是数据比例，不是后台任务，不增加任务状态框。索引页「载入更多」按钮内的 Spinner 与列表续页那一行的传输动画也不是独立任务面板。

统计页骨架按四张读数卡、两张环形图和三张分布图排版；重复页骨架按汇总、玻璃批量操作条、组头和文件行排版。加载占位与正文使用相同响应式列数和容器宽度。回收站网格与管理标题、汇总栏共享 `--board-content`；垃圾文件页不显示订阅新作，晚到的目录请求也不能重新插入该区域。
